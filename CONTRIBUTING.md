# Contributing

Thanks for helping improve Plan-Driven Delivery Loop.

## Proposing a change

1. Open an issue describing the workflow problem and a realistic example.
2. Explain which stage is affected and what observable behavior should change.
3. Keep rules narrow. Avoid adding universal requirements for one unusual project.
4. Preserve authorization boundaries, especially around Git pushes and other external writes.

## Pull requests

- Keep `SKILL.md`, `agents/openai.yaml`, and referenced files consistent.
- Use lowercase kebab-case for skill names.
- Do not leave scaffold placeholders or broken relative links.
- Explain how the change improves agent decisions, not only wording.
- Include a realistic before/after scenario for substantial behavior changes.
